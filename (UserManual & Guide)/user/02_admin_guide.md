# Admin guide

This guide is for **MyLENS admins and mentors**.

Use it to approve people, manage schools, review videos, and run Learning.

---

## Before you begin

You need:

- An admin account
- Access to the admin dashboard after login

---

## 1. Overview

Open **Overview**.

Here you can see:

- Key counts (schools, creators, pending items)
- Attention items that need action
- Shortcuts to common work

### Start with attention items

If something is waiting, Overview usually points you there first:

- Contest videos to review
- Learning assignments to review
- Creators waiting for approval
- New inquiries

---

## 2. People (approve creators)

New students often cannot work until you approve them.

1. Open **People**
2. Check **pending** accounts
3. Open a person and approve / activate when ready
4. Confirm they can sign in as a creator

### Tips

- Check school details before approving
- If a creator says the app is empty, confirm their status is active

---

## 3. Schools

1. Open **Schools**
2. Create a school, or open an existing one
3. Set status (for example active)
4. Share school access details / token when your process uses them

Keep school names clear so creators join the right one.

---

## 4. Contest video submissions

Open **Submissions**.

This list is for **campaign tourism videos only**.

1. Open a submission
2. Watch / check the video and details
3. Choose:
   - Approve
   - Request edits (revision)
   - Reject
4. Add clear notes when creators must fix something

### Do not mix this with learning homework

Homework reviews are under **Learning → Reviews**.

---

## 5. Learning workspace

Open **Learning**.

You will see three tabs:

| Tab | Purpose |
|-----|---------|
| **Lessons** | Build modules and lesson content |
| **Assignments** | Create homework tasks |
| **Reviews** | Approve creator homework submissions |

### How Learning is organised

- A **module** is a folder (example: Camera)
- A **lesson** is content inside a module (video, live class, document, link)
- An **assignment** is homework creators submit in My tasks

---

## 6. Lessons (build content)

1. Open **Learning → Lessons**
2. Create a **module** first (New module)
3. Add lessons into that module (Add lesson)
4. Fill title, type, links/files, schedule (for live classes)
5. Tick **Visible to creators** when ready
6. Save

### Catalogue tips

- The main screen shows existing content first
- Use **Add** only when creating new content
- Use **Edit** only when changing existing content
- Use the `⋯` menu for publish / unpublish / delete

---

## 7. Assignments (homework)

1. Open **Learning → Assignments**
2. Choose the module
3. Add assignment title and instructions
4. Choose submission format (text, link, file, or mixed)
5. Optional: due date
6. Tick **Visible to creators**
7. Save

Creators will find these under **Learning → My tasks**.

---

## 8. Publish rule (very important)

Creators see content only when **both** are published:

1. The **module** is published
2. The **lesson or assignment** is published (Visible to creators)

If either one is still Draft, creators will not see it.

After saving a draft, publish it before telling students to check.

---

## 9. Reviews (homework checking)

1. Open **Learning → Reviews**
2. Use the queue / filters to find waiting work
3. Open a submission
4. Read the answer / open the file or link
5. Choose:
   - Approve
   - Ask for revision
   - Reject
6. Write short, clear mentor notes when needed

Approved homework can update learning progress for the creator.

---

## 10. Inquiries

Open **Inquiries** to handle:

- School contact messages
- Partnership messages

Update status as you reply (for example contacted or closed), following your team process.

---

## Admin quick checklist

- [ ] Approve pending creators
- [ ] Keep schools up to date
- [ ] Review contest videos under Submissions
- [ ] Publish modules + lessons / assignments
- [ ] Review homework under Learning → Reviews
- [ ] Clear new inquiries

---

## Clear naming helps everyone

Use titles students understand, for example:

- Good: `Live class: Camera angles`
- Good: `Assignment: 30-second intro film`
- Avoid vague titles like `Test 1` or `Untitled`
