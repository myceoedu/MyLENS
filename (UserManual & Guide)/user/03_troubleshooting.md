# Troubleshooting

Use this page when something does not work.  
Try the steps in order.

---

## Login and account

### I cannot sign in

1. Check email and password carefully
2. Try **Forgot password**
3. Ask admin if your account is approved
4. Confirm you are opening the correct MyLENS website

### I registered but cannot use creator tools

- Your account may still be **pending**
- Ask a MyLENS admin to approve you under **People**

### Forgot password email did not arrive

1. Check spam / junk folders
2. Wait a few minutes and try once more
3. Ask admin/developer if email settings need checking

---

## Creator: Learning

### I cannot see any lessons

1. Refresh the page
2. Confirm you are on **Learning → Lessons**
3. Ask admin if the module and lessons are **published**
4. If only homework is missing, check **My tasks** instead

### I cannot see my homework

1. Open **Learning → My tasks** (not Lessons, not Submissions)
2. Ask admin if the assignment and its module are published
3. Refresh and try again

### I submitted a task but status did not change

1. Wait a moment and refresh
2. Confirm you pressed submit (not only save draft)
3. Check you included the required answer format (text / link / file)
4. Ask admin to confirm the submission appears under **Learning → Reviews**

### Mentor asked for revision

1. Open the task again in **My tasks**
2. Read the mentor notes
3. Update your answer
4. Submit again

---

## Creator: Contest video submissions

### I cannot create a submission

1. Check if the submission window is open (see Home)
2. Confirm your account is approved
3. Confirm your school/team setup is complete
4. Refresh and try again

### My video is stuck waiting

- Admin may still be reviewing it
- Check for notes if status is **Needs edits**
- Fix the requested items and submit again

### I uploaded / linked the wrong video

1. Open the submission
2. Edit if status allows
3. If locked, ask admin what to do next

---

## Admin: People and schools

### Creator says they cannot enter

1. Open **People**
2. Check account status is active / approved
3. Confirm role is creator
4. Ask them to sign out and sign in again

### Creator joined the wrong school

1. Check school details on their profile
2. Correct according to your process
3. Confirm with the school coordinator

---

## Admin: Learning publish problems

### Creators cannot see a lesson or assignment I added

Check all of these:

1. Item status is **Published** / **Visible to creators**
2. Parent **module** is also published
3. Creators are looking in the correct tab:
   - Lessons → Lessons tab
   - Homework → My tasks tab
4. Ask creator to refresh

### I edited content but creators still see old details

1. Confirm you saved the edit
2. Confirm you were editing the correct item (not creating a new one)
3. Ask creators to refresh

### Reviews queue is empty

- No creator has submitted homework yet, or
- You are on a filter with no matching status
- Try the default queue / clear search

---

## Admin: Contest submissions

### I cannot find a video

1. Check search and status filters
2. Confirm the creator submitted (not only draft)
3. Open the creator account and verify school

### Creator did homework but I cannot find it in Submissions

That is expected.

Homework is under **Learning → Reviews**,  
not under contest **Submissions**.

---

## Files and uploads

### File upload failed

1. Check file size limits shown on the form
2. Use a supported file type
3. Try a stronger internet connection
4. Try again later

### Link will not save

- Use a full link starting with `http://` or `https://`
- Remove extra spaces
- Try again

---

## Still stuck?

1. Note the exact screen name and what you clicked
2. Note any error message text
3. Contact your teacher (creators) or MyLENS technical admin
4. Include your account email and school name
